Product Overview

Semua yang server Anda butuhkan,
dalam satu dashboard.

Dari monitoring real-time hingga remediasi otomatis berbasis AI. Trazezzo menggabungkan observability kernel-level, agen AI proaktif, dan kontrol penuh server — semua dari browser.

Real-time Overview

CPU, RAM, load, uptime, disk usage, dan daftar service gagal — semua dalam satu layar. Update otomatis tanpa refresh.

AI Chat Agent

Tanya apa saja dalam bahasa natural. Agen AI menganalisis konteks server, menjalankan command, dan memberi jawaban langsung — mode agent penuh.

Proactive AI Agent

Agen berjalan 24/7 di background. Deteksi anomali, proposal perbaikan, dan eksekusi otomatis dengan allowlist keamanan.

eBPF Kernel Tracing

Tangkap syscall level kernel — execve, open, connect, kill. Visibilitas mendalam tanpa overhead. Butuh kernel 5.8+.

Multi-source Capture

Gabungkan journald, auditd, dan psutil metrics dalam satu timeline terpadu. Setiap event diatribusi ke user, agent, atau system.

Networking & Firewall

Kelola interfaces, routes, bonds, dan rules firewall dari UI. Lihat koneksi aktif dan diagnose masalah jaringan.

Container Management

Podman & Docker. Start, stop, inspect container. Lihat logs, resource usage, dan status dalam satu tempat.

Security & Credential Scan

SELinux status, SSH key management, dan scanner yang mendeteksi plaintext secrets di file config — tanpa expose nilai secret.

Timeline & Diagram

Visualisasi activity timeline 30 menit terakhir. Diagram topologi service dan dependency. Warm retention 7 hari di SQLite.

Web Terminal

Shell penuh via WebSocket. Akses server dari browser, kapan saja. Eksekusi command dengan approval flow keamanan.

File Editor & GitHub

Editor file web-based dengan syntax highlighting. Integrasi GitHub: secure token storage, repo list, commit, push, pull request.

Diagnostic Suite

SOS report generation, kdump config, tuned profiles, dan package updates (apt/dnf). Semua alat diagnostik dalam satu menu.

Development Mode

Pilih bagaimana AI Anda bekerja.

Dua mode operasi untuk AI agent. Sesuaikan dengan tingkat kepercayaan dan kebutuhan otomasi Anda.

Default

Calm Mode

Advisory only. AI mengawasi dan menyarankan, Anda yang eksekusi.

  • ✓ Monitoring 24/7 semua metrik server
  • ✓ Deteksi anomali (CPU spike, disk full, OOM)
  • ✓ Rekomendasi perbaikan via dashboard & chat
  • ✓ Timeline event dengan atribusi aktor
  • ✓ Tidak ada eksekusi tanpa persetujuan manual
Pro

Aggressive Mode

Auto-remediation. AI mendeteksi dan langsung memperbaiki, dengan allowlist keamanan.

  • ✓ Semua fitur Calm Mode
  • ✓ Auto-restart service yang crash
  • ✓ Auto-kill proses OOM
  • ✓ Auto-cleanup journal & apt cache
  • ✓ Renice proses CPU hog
  • ✓ Approval queue untuk action di luar allowlist

Aggressive Mode Allowlist — hanya action ini yang auto-eksekusi

service.restart
service.start
process.kill_oom
disk.cleanup_journal
disk.cleanup_apt
process.nice
